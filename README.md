# KakTing

Prototype marketplace tutor kontekstual antar-mahasiswa BINUS — "Diajari, bukan dikerjakan."
Tugas Final ENPR6312 Venture Creation.

## Fitur
- Cari tutor per mata kuliah (tier harga berbasis pengalaman, VIP, verifikasi KTM + nilai)
- Chat dengan mentor sebelum booking
- Booking sesi: durasi, paket bundle, promo, pledge anti-joki
- Kalender & daftar sesi, rekaman sesi, ulasan mentee, tip ke mentor
- Program loyalty (Perunggu → Platinum)
- Halaman profil Mentee & Mentor
- Iklan hero auto-slide, tema terang/gelap

## Cara menjalankan
Buka `index.html` di browser, atau host lewat GitHub Pages.

### GitHub Pages
1. Buat repository baru, unggah semua isi folder ini (jaga struktur `assets/`).
2. Settings → Pages → Source: branch `main`, folder `/root`.
3. Situs tampil di `https://<username>.github.io/<repo>/`.

Butuh koneksi internet untuk memuat font Google. Semua gambar & logika sudah termuat lokal.
